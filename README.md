<h2 align="center">🧩 What I've Built</h2>

<p align="center"><i>A look at the real-world work I've shipped: what I did and what I used.</i></p>

### 🏥 Disability-Services Platform: Backend Rebuilt From Scratch
A disability-services platform whose backend I rebuilt from the ground up.
- Built a complete authentication system with user registration and OTP verification
- Designed and tested REST API endpoints for care-plan management, shift scheduling, and user profiles, with input validation using Zod
- Set up automated transactional emails to support registration and notification workflows

**Tech:** `Next.js` `Prisma ORM` `SQL` `Zod` `Nodemailer` `ZeptoMail` `REST APIs`

### 📊 Enterprise Compliance Platform
A core compliance platform used by **25,000+ compliance professionals across 23 countries**.
- Rebuilt the core dashboard APIs in PHP after a migration from NestJS, consolidating logic and removing duplicate code
- Built cross-role date filtering that stays in sync across dashboards, graphs, and popups
- Diagnosed and fixed recurring production issues: API bugs, date-calculation errors, cron scheduling failures, and email-delivery problems

**Tech:** `PHP` `REST APIs` `Cron Jobs` `Production Debugging`

### 💹 Investment-Education Platform
A subscription-based platform covering stocks, crypto, and metals, with live portfolio tracking.
- Built backend APIs and database logic behind the Investment History, Current Holdings, and Position Tracker modules
- Integrated a live gold-price feed (EUR) for automatic, real-time pricing updates
- Developed and debugged core trading features, including form handling and pre-filled field logic

**Tech:** `Backend APIs` `Database Logic` `Live Data Feed Integration`

### 🗂️ Compliance Management System
A compliance management system built for a professional-services firm.
- Built date-filtering and compliance-calculation logic, plus Excel report generation, across dashboards, graphs, and popups for multiple user roles
- Automated compliance checks and daily email reports, tested across approximately 330 client companies

**Tech:** `Excel Report Generation` `Scheduled Jobs` `Email Automation` `Role-Based Dashboards`

### 🔐 Website Security Review and Cleanup
A security review across two business websites: a law firm and a financial-consulting firm.
- Audited both codebases and removed malicious files and hidden scripts
- Strengthened login security and access control with password hashing and stricter validation checks
- Secured file uploads by validating file types and restricting upload-folder access

**Tech:** `Security Auditing` `Password Hashing` `Input Validation` `Access Control`

### 🏭 Compliance Dashboard for a Global Manufacturer
A compliance dashboard for a global automotive-parts manufacturer.
- Built PHP-based dashboard APIs with proper login-based access control, replacing hardcoded user and role values
- Built dashboards with graphs, tables, role-based popups, search, and Excel export
- Automated daily email reports through scheduled jobs, fixing data-accuracy and formatting issues

**Tech:** `PHP` `REST APIs` `Role-Based Access` `Scheduled Jobs` `Excel Export`

### 📚 E-Book Management System (Personal Project)
A secure full-stack web app for managing digital book records.
- Built user authentication, real-time content updates, and search/filter functionality
- Applied MVC architecture and SDLC practices, with secure session handling and reliable data persistence

**Tech:** `Java` `JDBC` `MySQL` `HTML` `CSS` `JavaScript` `Bootstrap` `React.js`
